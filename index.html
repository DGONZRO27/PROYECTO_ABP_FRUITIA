FruitVision AI

Proyecto académico para clasificar el estado de frescura de frutas mediante una red neuronal convolucional. El foco está en la fundamentación matemática, la arquitectura neuronal, la evaluación y la aplicación práctica.

Comprensión del problema

Se define como objetivo la clasificación de fruta fresca vs. deteriorada para cuatro categorías.

Preparación de datos

Se trabaja con separación por origen y se evita mezclar entrenamiento y prueba en la misma fuente.

Diseño del modelo

Se reutiliza la exportación de Teachable Machine basada en MobileNetV2 y se valida la arquitectura real.

Evaluación y despliegue

Se calculan métricas reales y se prepara una aplicación de clasificación interactiva.

Tutorial paso a paso

1. Preparación

Se cargan imágenes con tamaño 224×224 y se convierten a RGB.

2. Preprocesamiento

Se normaliza el rango de píxeles conforme a la arquitectura base usada por la exportación.

3. Predicción

La red calcula probabilidades para cuatro clases de fruta y estado de frescura.

4. Evaluación

Se compara la salida contra etiquetas reales, calculando precisión, recall y F1-score.

Resultados reales y limitaciones

El proyecto documenta de forma explícita la diferencia entre la evaluación interna de Teachable Machine y la evaluación independiente con un conjunto reservado de prueba. No se asume un valor global de exactitud sin la correspondiente verificación experimental.

La exportación disponible confirma un modelo entrenado basado en MobileNetV2, con cuatro salidas y una entrada de 224×224×3. El repositorio conserva la arquitectura y los pesos originales sin reentrenamiento.

La versión final del proyecto prioriza la evidencia observada, la ejecución local del modelo exportado, la claridad de la documentación y la transparencia metodológica sobre el alcance de la solución.
